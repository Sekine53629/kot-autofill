# kot-autofill

KING OF TIME の「スケジュール申請」画面で、各日の**申請スケジュール**を選ぶと、同じ日の
**休暇種別 / 休暇モード / 申請メッセージ**を自動で埋めるブラウザ用スクリプトです。

毎月の申請で同じ入力を繰り返す手間を減らすことを目的にしています。

## 動作イメージ

| 選んだ申請スケジュール | 申請メッセージ | 休暇種別 | 休暇モード |
|------------------------|----------------|----------|------------|
| 通常勤務(10-19時)      | 早番           | 変更しない | 変更しない |
| 10:30-19:30            | 遅半           | 変更しない | 変更しない |
| 通常勤務(11-20時)      | 遅番           | 変更しない | 変更しない |
| 公休                   | 公休           | 公休     | 全日休     |

- 手入力済みのメッセージ（スクリプトが入れた値以外）は上書きしません。
- 「公休」から出勤シフトに選び直した場合、スクリプトが入れた休暇種別・休暇モードを解除します。
- 勤務日種別は KING OF TIME 側が自動設定するため、スクリプトは触りません。

## 操作パネル（画面左下）

実行すると、ブラウザの**左下に小さなパネル**が出ます。Console を開いていなくても
動作状況がわかり、ボタンひとつで止められます。

```
┌────────────────────────────┐
│ ● 自動入力 ON   クリックで停止 │
│ 09/23 「早番」を入力          │
└────────────────────────────┘
```

| 表示 | 意味 |
|------|------|
| 緑のランプ＋`自動入力 ON` | 有効。スケジュールを選ぶと自動入力される |
| 灰のランプ＋`自動入力 OFF` | 停止中。ページには一切干渉しない |
| 下段のグレー文字 | 直近の自動入力の結果（例: `09/23 「早番」を入力`） |
| 下段の黄色い文字 | 警告（例: `09/23 メッセージ欄が見つからない`） |

- **パネルをクリックするたびに ON / OFF が切り替わります。**
- ON / OFF の状態はブラウザに保存され（`localStorage`）、次回も同じ状態で始まります。
- パネルは Shadow DOM で隔離してあるため、KING OF TIME 側の CSS と干渉しません。
- Console から `__kotAutofill.disable()` / `.enable()` / `.destroy()` でも操作できます。

## 使い方

### Console に貼り付ける（いちばん手軽）

1. KING OF TIME のスケジュール申請画面を開く
2. DevTools（F12）の Console を開く
3. [kot-autofill.js](kot-autofill.js) の全文を貼り付けて Enter
4. 左下にパネルが出れば有効（Console にも `[kot] 待機中...` と出ます）

ページを再読み込みすると無効になるので、その都度実行してください。

> **初回は貼り付けがブロックされます。** Chrome / Edge は自己 XSS 対策として、
> Console への初回の貼り付けを拒否します。`allow pasting` と**手で入力**して
> Enter を押してから、改めて貼り付けてください（プロファイルごとに 1 回だけ）。

### DevTools の Snippets に保存する（貼り付けを省く／拡張機能は不要）

毎回貼り付けるのが手間なら、ブラウザ標準の機能だけで保存できます。
**拡張機能のインストールが許可されていない環境でも使えます。**

1. DevTools → **Sources** タブ → 左ペインの **Snippets**
2. **New snippet** で `kot-autofill` を作り、スクリプト全文を貼り付けて保存（Ctrl+S）
3. 以降は Snippets から選んで **Ctrl+Enter** で実行

スクリプトはブラウザに保存されるので、次回以降は貼り付け不要です。

### 拡張機能が使える場合

[Tampermonkey](https://www.tampermonkey.net/) などのユーザースクリプトマネージャに登録すると、
画面を開くたびに自動で有効になり、実行操作そのものが不要になります。
`@match` は自社の KING OF TIME の URL に合わせてください。

```javascript
// ==UserScript==
// @name         kot-autofill
// @match        https://s2.kingtime.jp/admin/*
// @run-at       document-idle
// ==/UserScript==
```

## カスタマイズ

スクリプト冒頭（IIFE の先頭）の `RULES` を書き換えます。キーは画面の
**申請スケジュールの表示名**と一致させてください（全角/半角・空白の違いは吸収されます）。

```javascript
const RULES = {
  "通常勤務(10-19時)": { memo: "早番", leave: null },
  "公休":              { memo: "公休", leave: { type: "公休", mode: "全日休" } },
};
```

- `memo` — 申請メッセージ欄に入れる文字列
- `leave` — `null` なら休暇種別・休暇モードに触らない。設定する場合は `{ type, mode }` を表示名で指定

## 動作確認

### 自動テスト

KING OF TIME の申請画面を模した DOM を jsdom 上に組み、スクリプトの挙動を検証します。

```bash
npm install
npm test
```

検証しているのは**スクリプト自身のロジック**（パネルの表示・ON/OFF・状態の保存・
再実行時の二重登録防止・手入力の保護・公休の設定と解除）です。
**セレクタが実画面と一致するかは検証できません**ので、下記の手動確認も必要です。

### 手動確認

パネルの見た目・ON/OFF の挙動は、**どのページでも確認できます**。適当なサイトの Console に
貼り付ければ左下にパネルが出ます。`requestedSchedulePatternList_` で始まる id を持つ
`<select>` が無いページでは自動入力側は一切動かないため、安全に試せます。

自動入力そのものは KING OF TIME の実画面でしか確認できません。初回は 1 日分だけ選んで、
パネル下段に `09/23 「早番」を入力` と出るか、黄色い警告が出ていないかを確認してください。

## 注意

- KING OF TIME の DOM 構造（`requestedSchedulePatternList_*`、`leave_type_code1*`、
  `input.htBlock-textS` などの id / class）に依存しています。画面仕様が変わると
  動かなくなる可能性があります。
- 自動入力はあくまで補助です。**申請前に必ず内容を目視で確認**してください。
- 非公式のスクリプトであり、株式会社ヒューマンテクノロジーズとは無関係です。
